# MariyaTakeuchiQuiz（竹内まりや風・プログラミングクイズ）

このリポジトリは、C#（Windows Forms）で作成した  
**「竹内まりや風」プログラミングクイズアプリ**です。

曲タイトル風の問題文、歌詞のような選択肢、  
レトロで優しい UI をイメージした、  
遊び心のあるクイズアプリになっています。

---

## ✨ アプリの特徴

- 竹内まりや風の世界観で統一されたクイズ  
- Windows Forms で動作するデスクトップアプリ  
- 選択式クイズ形式  
- 正解すると音符やメッセージが表示される  
- プログラミング学習を「音楽のように楽しく」するコンセプト

---

## 🚀 使い方

1. ZIP をダウンロード  
2. 展開して Visual Studio で `.sln` を開く  
3. 実行するとクイズアプリが起動  
4. 好きな問題を選んで回答  
5. 正解すると音符やメッセージが表示されます

## 🐘 データベース（PostgreSQL）

クイズの問題データは PostgreSQL に保存しています。

### テーブル構成（例）

- question : 問題文  
- option1〜option4 : 選択肢  
- correct_answer : 正解番号  

C# 側では Npgsql を使用して DB から問題を読み込み、  
アプリ起動時にランダムに並べ替えて出題します。
